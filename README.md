# Project Airaavat Campaign Website

A static, mobile-friendly campaign landing page intended for GitHub Pages. No framework, build step, database, or paid subscription is required.

## Important: this is a draft
Before publishing, update:
- Funding milestone amounts and line items to reflect purchases already made, grant money received, and the actual remaining requirement.
- UPI ID and QR code (intentionally omitted from this draft).
- Exact GitHub repository, LinkedIn post, and ground-trial video URLs.
- Current project phase label (V2 / V2.5) and exact as-built status.
- Contact method and publication/update date.

Do not present the ₹10,000 academic research grant as a formal institutional BHU grant unless the paperwork actually says that. If you mention the grant publicly, confirm the donor is comfortable with public attribution.

## Edit the site
Edit `index.html` in GitHub's web editor or locally. It is plain HTML/CSS/JS.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository, e.g. `airaavat-campaign`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for deployment to finish. GitHub will show the public URL in Settings → Pages.
7. Open that URL in an incognito browser where you are not signed in to GitHub. Test on mobile too.
8. Only then replace the Claude Artifact link in Instagram bio and LinkedIn.

## Update later
Edit `index.html`, commit the change, and GitHub Pages will redeploy it. Keep a copy of receipts and a simple public ledger for contributions and purchases.

## Safety and transparency
- The contribution box does not yet accept payments; add a payment ID/QR only after checking you are comfortable making it public.
- Do not include bank account numbers, cheque details, signatures, or other unnecessary financial information.
- Clearly distinguish measured results, estimates, and future plans.
- A contribution is voluntary project support, not an investment and not a promise of financial return.
